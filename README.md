# Joshua Mwalukimba — Premium Developer Portfolio

Modern, multi-page portfolio website for Joshua Mwalukimba (Full-Stack Developer).

**Positioning:** Full-Stack Software Developer & Business Solutions Developer  
**Design:** Midnight navy + Electric blue + Subtle glassmorphism  
**Stack:** Next.js 15 · TypeScript · Tailwind CSS · Lucide icons

---

## Pages

| Route | Description |
|-------|-------------|
| `/` | Home — Hero, Featured projects, Services preview, Process, CTA |
| `/projects` | All projects listing |
| `/projects/[slug]` | Individual case study (Problem → Solution → Tech → Results) |
| `/services` | Full services with deliverables |
| `/about` | About, tech stack, values |
| `/process` | 6-step working process |
| `/contact` | Contact form + direct channels |
| `/resume` | CV download |

## Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Run development server
npm run dev

# 3. Open http://localhost:3000
```

## Important: Replace placeholders

1. **Live URLs** — Edit `src/lib/projects.ts` and put real live demo + GitHub links
2. **Images** — Add project screenshots to `public/images/projects/`
3. **Your photo** — Add professional photo and update the Home page hero
4. **Contact form** — Currently simulates success. Connect to EmailJS, Resend, or your API later
